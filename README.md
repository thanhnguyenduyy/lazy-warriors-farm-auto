# Lazy Warriors Farm Auto

Bản userscript **tự động hóa** cho SSV Farm.

## Tệp trong thư mục

- `script.user.js`: userscript auto (cài bản này).
- `script.meta.js`: metadata cập nhật.

## Cài đặt

1. Cài trình quản lý userscript (Tampermonkey/Userscripts).
2. Cài [script.user.js](./script.user.js).
3. Mở `https://at-sp.ssvhue.work/`, tải lại trang và mở bảng điều khiển bằng **icon ngôi sao (⭐)**.

## Ghi chú

- Đây là bản tách riêng khỏi Guild Chat. Nếu cần chat, cài thêm bản chat chung (`lazy-warriors-farm-chat`).
- `@updateURL`/`@downloadURL` trỏ tới repo `thanhnguyenduyy/lazy-warriors-farm-auto`. Khi phát hành, hãy đồng bộ `@version` giữa `script.meta.js` và `script.user.js`.
